# Electroneum Projects From Africa

Welcome to the **Electroneum Projects From Africa** registry! This is the central hub for African builders to showcase their Web3 dApps and applications built on the Electroneum blockchain.

## 🎯 What is This?

This is a **project registry** where African Web3 developers can submit links to their GitHub repositories. Builders keep their code in their own repositories and simply register their projects here.

---

## 📋 How to Submit Your Project

### Quick Steps:

1. **Go to:** https://github.com/electroneumafrica/Electroneum-Projects-From-Africa/blob/main/PROJECTS_REGISTRY.md
2. **Click the pencil icon** (Edit this file)
3. **Add your project** in this simple format:

```markdown
#### [Your Project Name]
- **Developer:** [Your name]
- **Country:** [Your country]
- **Repository:** https://github.com/your-username/your-repo
- **Live Demo:** https://your-live-url.com (or "In development")
- **Description:** [What your project does - 1-2 sentences]
- **Tech Stack:** [Technologies used]
- **Status:** ✅ Submitted - [Date]
```

4. **Scroll down** and click "Commit changes"
5. **Create a Pull Request**
6. **Done!** We'll review and approve your submission

---

## ✅ What We Need

Your project repository should have:
- ✅ Public GitHub repository
- ✅ Working code (even if incomplete/MVP)
- ✅ README.md explaining what it does
- ✅ SETUP.md or basic setup instructions
- ✅ Active development (commits)

**You don't need to:**
- Upload code here
- Have a finished product
- Have mainnet deployment
- Have perfect documentation

You can keep improving your project after submission!

## 🚀 Getting Started

3. Add your project to the registry via Pull Request

3. Click on repository links to verify project status

## ❓ FAQ

**Q: Do I submit my complete code here?**
A: No! You submit a link to your own GitHub repository.

**Q: Can I continue developing after submission?**
A: Yes! Keep pushing code to your own repository.

**Q: What if my project is still in development?**
A: That's fine! We accept MVPs and projects in progress.

**Q: How long does approval take?**
A: 3-5 business days for review.

**Q: Can I update my project information after approval?**
A: Yes! Just create another PR to update the registry.
