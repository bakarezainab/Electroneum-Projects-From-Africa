# Electroneum Projects From Africa

Welcome to the **Electroneum Projects From Africa** registry! This is the central hub for African builders to showcase and submit their Web3 dApps and applications built on the Electroneum blockchain.

## 📋 Project Submission Guidelines

### How to Submit Your Project

1. **Ensure your project repository is public** on GitHub
2. **Create a Pull Request** to this repository with your project details
3. **Fill in the simple form** (see below)
4. **Wait for review** - our team will validate your submission
5. **Your project gets merged** and appears in the registry

---

## 🚀 How to Submit

### Option 1: Edit README Directly (Easiest)

1. Go to: https://github.com/electroneumafrica/Electroneum-Projects-From-Africa
2. Open the `PROJECTS_REGISTRY.md` file
3. Click "Edit this file" (pencil icon)
4. Add your project in this format:

```markdown
#### [Your Project Name]
- **Developer:** [Your name]
- **Country:** [Your country]
- **Repository:** https://github.com/your-username/your-repo
- **Live Demo:** https://your-live-url.com (or "In development")
- **Description:** [1-2 sentence description]
- **Tech Stack:** [Technologies used]
- **Status:** ✅ Submitted - [Date]
```

5. Scroll down and click "Commit changes"
6. Add a commit message: `Add [Your Project Name] to registry`
7. Select "Create a new branch" and click "Propose changes"
8. Click "Create Pull Request"

---

### Option 2: Create a Pull Request (Traditional Way)

1. Fork this repository
2. Clone your fork:
   ```bash
   git clone https://github.com/your-username/Electroneum-Projects-From-Africa.git
   cd Electroneum-Projects-From-Africa
   ```
3. Edit `PROJECTS_REGISTRY.md` and add your project
4. Commit and push:
   ```bash
   git add PROJECTS_REGISTRY.md
   git commit -m "Add [Your Project Name] to registry"
   git push origin main
   ```
5. Go to the main repository and create a Pull Request

---

## 📝 Submission Format

When you submit, include:

```markdown
- **Repository:** [Link to your GitHub repo]
- **Live Demo:** [URL or "In development"]
- **Description:** [What your project does - 1-2 sentences]
- **Tech Stack:** [Technologies used]

```

## ✅ What We Look For

Your repository should have:
- ✅ Working code (even if incomplete)
- ✅ README.md explaining what it does
- ✅ SETUP.md or instructions to run it
- ✅ Public GitHub repository
- ✅ Active development/commits

**You can keep pushing code after submission!** Your project will be updated automatically as you make improvements.

## ❓ FAQ

**Q: Do I need to submit a complete project?**
A: No! We accept MVPs and projects in development. You can keep coding after submission.

**Q: Can I update my repository after submission?**
A: Yes! Your project will be updated automatically.

**Q: How long does review take?**
A: 3-5 business days

**Q: Can I submit multiple projects?**
A: Yes! Create multiple PRs, one per project.
